MosaicPDF is a free invoice maker that runs entirely in the browser. Pick a template, click any text on the invoice to edit it, and download a pixel-perfect PDF. No account, no upload.

## Features

- **Edit on the page**: no forms, click any text and type. What you see is the PDF you get
- **6 layouts × 9 themes**: mix and match, then customize color, font, logo and border
- **Private by design**: invoices, clients and numbering are stored on your device, nothing is sent to a server
- **Bilingual invoices**: print labels in two languages, like "Facture / Invoice", for clients abroad
- **Pay-by-QR code**: add a SEPA QR code so clients pay in seconds from their banking app
- **Works offline**: installable, with backup export anytime

## Technical Stack

- Next.js with React Server Components and next-intl for i18n
- In-browser PDF generation with selectable text
- IndexedDB for local-first storage
